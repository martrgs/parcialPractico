Sistema de Inventario y almacén

Descripción
Sección B: Parcial práctico
Este proyecto tiene como objetivo gestionar un inventario, permitiendo organizar y administrar la información de los productos.

Objetivo
Desarrollar un proyecto práctico para la gestión y el control de un inventario.


Instalación
Clonar el repositorio.
Abrir la carpeta del proyecto en Visual Studio Code.
Instalar las dependencias necesarias, si aplica.
Ejecutar el proyecto según su configuración.
